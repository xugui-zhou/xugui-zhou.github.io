The three-period settling rule is a teaching simplification, not a universal ADC rule. Advance 3 already includes reading DATA. Reading clears DRDY; a cleared DRDY immediately afterward is expected.

What the controls mean

  • Prepare fields: fills suggestions and nominal test conditions, without writing CONFIG or DAC.
  • Dropdowns: proposed fields. Copy transfers their encoded byte into the separate write box.
  • Write CONFIG: sends the write-box byte. Read CONFIG checks acceptance.
  • Advance 3, read each: generates and reads samples. Changing an input alone does not refresh DATA.
  • Save checkpoint: saves the latest sample. Go back and acquire again after changing settings.
  • Optional observation: linked tank/current/register display, with no duplicate controls. The instructor’s dynamic plant is a separate illustration, not student evidence.

Independent tasks retain procedural guidance but give no prepared settings or expected numerical answers. They assess application and explanation, not discovering the whole debugging method unaided. References remain available.

Suggested session flow

5 min plant demonstration → 18 min guided examples (A hands-on; B–D instructor-led with short pair responses) → 3 min structure discussion → 23 min independent work → 3 min evidence discussion → 8 min submission. The remaining 15 min are buffer, not additional required content. Repeating B–D individually is available when needed; follow your instructor’s pace.

Neither a browser-local draft nor a downloaded file is a Moodle submission. This website does not upload anything. Keep your JSON as a local copy. This is an open-resource offline lab, not a secure exam.

Scope

Signal conversion, configuration/read-back, modeled settling, saturation, DAC feedback and recovery evidence. Not real wiring, SPI waveforms, vendor drivers, PID tuning or network diagnosis. A simulated software tag is not a running PLC control loop.
