Signal and conversion model

ADC: unsigned 12-bit unipolar. Nominal reference 3.3 V. Gain 1, 2, 4 or 8. Output rates 5, 20, 100 or 1000 SPS. The user advances simulation time by one output period.

LSB = Vref / (4096 × G)
C = clamp(floor(4096 × G × Vin / Vref), 0, 4095)
Vestimated = C × Vref_assumed / (4096 × G)
I_mA = Vestimated / 0.15
h_m = (I_mA − 4) / 8
DAC voltage = 3.3 × D / 4096

Tank transmitter: h = 0–2 m maps to 4–20 mA. A 150 Ω shunt produces 0.6–3.0 V. This MCU ADC code model differs from the earlier PLC module's 0–27648 engineering code model. Do not mix them.

At 3.3 V, gain 1: 1 LSB = 0.805664 mV. For h = 0, 1, 2 m, expected floor codes are 744, 2234, 3723. A settled, nominal simulated measurement must match exactly. A physical experiment would need a tolerance budget.

Practice example: DAC code 2048 produces 1.650 V. ADC CH2 at gain 1 returns 2048 with a nominal 3.3 V reference. Use the stated formula for other codes. The shared ideal reference hides common-reference error, so this test alone cannot establish absolute accuracy.

Simulated SPI frame specification

Mode 0, MSB first, two bytes under one conceptual CS assertion. A read transmits [address, 0x00], and returns [0x00, value]. A write transmits [0x80 | address, value], and returns [0x00, 0x00]. Write response is not an acknowledgement of the accepted value.

Write CONFIG 0x81: TX 81 81, RX 00 00
Read CONFIG:       TX 01 00, RX 00 81
Read ID:           TX 00 00, RX 00 42
Read DATA: read address 03, then address 04
Code = ((DATA_H & 0x0F) << 8) | DATA_L

Mode mismatch returns 0xFF on reads, rejects writes and latches SPI_ERROR. This is an explicit teaching rule. Real devices need not fail this way. A DAC high-byte write followed by a low-byte write is not atomic in this model, but no time elapses unless you advance conversion.

Settling uses an illustrative recurrence: transient voltage = (previous filtered voltage + present input) / 2 for two outputs, then the exact input on output three. It is not a physical sinc³ implementation. At 20 SPS, the settled output appears after 150 ms following a configuration change. Reading transient data does not make it valid.

Time in this model is deterministic output-period time. SAR bit trials, delta-sigma internal clocks, analog acquisition timing and true conversion pipeline latency are not simulated.

Source time stops on the frozen-transmitter scenario; conversion time keeps advancing. The source timestamp is instrumented ground truth provided by this simulator. An ordinary 4–20 mA loop does not carry a source timestamp, so real freeze detection needs independent evidence or an additional diagnostic channel.

Assumptions and limits

No physical hardware, noise, INL/DNL, power-on timing, isolation, electrical loading, compliance voltage, real packets, PLC execution or safety behavior. Exact agreement here validates the configured mathematical chain. It does not certify hardware accuracy. The earlier two-tank course demo remains a separate reference for later system-level labs.
