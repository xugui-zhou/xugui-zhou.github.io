    Reference: equations and model boundaries

    SP = 1 m. Pump output u is a fraction from 0 to 1. Bias 0.5 balances nominal outlet flow at the setpoint. Ki = 0 gives proportional control; a changed outlet load can produce a steady-state error. The extra outlet load begins at 60 s in EVERY run. IAE integrates absolute error over 0–120 s. Recovery is the first time after 60 s that level enters ±0.02 m and remains there until the run ends; “not reached” is not zero.

    Delay and jitter affect source-sample delivery. The receiver rejects older source timestamps. Hold keeps the last pump command and freezes the integrator while stale; Stop inlet commands zero and freezes it. Local control requires an additional available local measurement path. It is an architectural comparison, not a network setting that repairs missing data.
