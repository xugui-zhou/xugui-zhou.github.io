Optional · reproduce the Lecture 10 model (3–5 min; no submission)

This is the unsaturated ideal tank with P control: x[k+1] = x[k] − g x[k−d], with x[k] = 1 m for k ≤ 0. x is level deviation, not absolute level. The assessed tasks below use a different, leaky tank with PI control.

Try g = 1.2 with d = 0 and d = 1. Then use d = 1, g = 0.3 and zoom: a small negative excursion is still an oscillation. These stability bounds do not apply directly to the PI tasks.

    Reference: equations and model boundaries

    SP = 1 m. Pump output u is a fraction from 0 to 1. Bias 0.5 balances nominal outlet flow at the setpoint. Ki = 0 gives proportional control; a changed outlet load can produce a steady-state error. The extra outlet load begins at 60 s in EVERY run. IAE integrates absolute error over 0–120 s. Post-load recovery is measured FROM 60 s until level enters ±0.02 m and stays there through 120 s. Burst-recovery timestamps are separate: burst end, first accepted/usable post-burst sample, and sustained level recovery observed before the 60 s load step. “Not observed” is not zero.

    Delay and jitter affect source-sample delivery. The receiver rejects older source timestamps. Hold keeps the last pump command and freezes the integrator while stale; Stop inlet commands zero and freezes it. Local control requires an additional available local measurement path. It is an architectural comparison, not a network setting that repairs missing data.
