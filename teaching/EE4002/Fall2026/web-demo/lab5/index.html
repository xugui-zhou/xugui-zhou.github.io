    Reference: equations and model boundaries

    CAN compares identifiers among frames ready to transmit. Ethernet FIFO uses arrival order. Priority queueing selects a ready sensor frame before a ready background frame. Neither can interrupt a frame already transmitting. The model omits retransmission and detailed physical-layer effects. Maximum age uses the displayed finite observation window and includes the final hold after the last acquisition.
