    Device & control reference — available in every task

    Model: one receiving tank, A = 0.50 m²; h = 0–2 m. Inlet maximum = 0.020 m³/s. Outlet is a constant-flow disturbance. This is not the two-tank demonstration elsewhere in the course. Lab flow values differ from the L5 worked example: use the values shown in the loaded task, not the slide’s numerical answer.

    Δh = (qin − qout) Δt / A

    ON/OFF: h ≤ LOW sets FillDemand ON; h ≥ HIGH sets it OFF; between limits retain its previous value. Initial demand is OFF. An invalid level first clears FillDemand. High-high at 1.60 m, source loss or invalid level overrides control and latches TRIPPED.

    Recovery: clear the cause → Reset to IDLE → release Start → press Start again. Reset never starts the pump. Stop blocks Start. Held Start is not a new press.

    The controller updates every 0.1 s. A normal control update uses the current level, then the tank advances for one interval. Boundary tests below deliberately apply an immediate update while paused.

    Command (%) is not measured flow. The blocked-inlet fault leaves the command intact but sets actual inflow to zero. The visualization assumes ideal pump feedback; it does not model a physical drive or network.

    Optional P/PI: a different actuator assumption — a continuously adjustable pump with ideal linear flow qin = 0.020 u/100. e = SP − h; u* = bias + Kp e + J; ΔJ = Ki Ts e; applied u = clamp(u*, 0, 100). Kp is %/m, Ki is %/(m·s). Conditional integration prevents further windup. D is omitted.

    Simulation clips the level at 0 and 2 m; conclusions near empty/overflow limits require a more complete model. Do not use this teaching controller for equipment safety.
