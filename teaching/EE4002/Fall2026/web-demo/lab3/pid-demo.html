Try one controlled comparison

Start with P and Bias = 0: with Kp = 100, expect a steady level of 0.50 m. Repeat with PI (Ki = 2) and watch the integral build the required pump output. Then try P with 50% bias. Always Apply and Restart for each comparison; observe long enough for settling, using the same supply and elapsed time.

Ki = 0 stops further integral accumulation but retains the existing integral memory after a live change. Restart clears it. Changing Bias also preserves existing integral memory on Apply and may cause an output jump. D acts on filtered level rate, not on setpoint error.

What this demonstration models

Same tank and PID engine as PLC Studio: area 0.50 m², pump flow lag τ = 2 s, outlet 0.010 m³/s, setpoint 1.00 m, initial level 0.80 m, initial inlet flow zero. Fixed Ts = 0.10 s and derivative filter Tf = 0.20 s. Demo Bias = 0% by default, with optional 50% nominal bias and conditional anti-windup. Formal PLC Studio tasks retain their original fixed 50% bias.

This separate practice session does not edit your PLC program or task evidence. It runs the baseline safety logic automatically. A high-high trip at 1.60 m stops the pump; use Restart to begin a new trial. Simulation continues beyond 120 s. The plots keep up to 300 s of recent history; use Pause to inspect a response. Restart clears the current trial. Reset all also restores default settings.

Why introduce bias after P and PI?

At nominal supply, 50% pump output balances the 10 L/s outlet. Without bias, P alone needs e = 50/Kp to produce this output; PI can build it in its integral state. With a known 50% bias, P can reach 1 m in this nominal condition. A changed load still needs correction. Bias is optional, not a substitute for integral action.

Where do the model-based gains come from?

G(s) = k / [s(τs + 1)], k = 0.0004 m/(%·s), τ = 2 s. Choose target poles −p and −1/λ (twice), with p = 0.43 s⁻¹ and λ = 25 s.

Kp = τ(1/λ² + 2p/λ)/k = 180 %/m
Ki = τp/(kλ²) = 3.44 %/(m·s)
Kd = [τ(p + 2/λ) − 1]/k = 50 %·s/m.

This preset uses 50% bias, as in the lecture model-based comparison. These gains match an ideal continuous characteristic polynomial. They are a design candidate, not a universal optimum. The real demonstration includes sampling, filtering, limits and trips. τ alone cannot specify optimal PID gains.
