    PI / PID block parameters

    Studio Bias is fixed at 50%: u = 50 + Kp × e + J + D, limited to 0–100%. At nominal supply and outlet, 50% balances flow. Zero P-only error here does not mean proportional control rejects every disturbance.

    Generated project source (read-only)

    The drawing and parameters form one program. Downloading this source loads the same networks into the virtual CPU. Existing ST-style project files can be imported.

    LAD instruction and scan rules

    Contacts in series mean AND. Parallel branches mean OR. NO tests TRUE; NC tests FALSE. These symbols test Boolean variables, not physical button wiring. Empty branches fail Check rather than acting as bypass wires.

    A normal coil writes its Boolean result every scan. SET and RESET retain an M1–M4 memory bit when their network is false. If both write the same bit in one scan, the last executed network wins. STOP and Download clear all memory bits and timers in this simulator.

    TON accumulates elapsed time while power reaches it, sets Q at the preset, and resets ET/Q when incoming power is false. Presets use simulated seconds. Each T1–T4 instance may occur once. A contact reading a timer or memory before its writer executes sees the previous value.

    Networks execute top to bottom within each phase. TripCause executes before the provided supervisor updates IDLE/AUTO/TRIPPED. PumpEnable executes afterward, using the updated Auto and Trip tags. Exactly one normal TripCause coil and one normal PumpEnable coil are required. The provided state machine and PID routine remain fixed.

    Model and execution reference
    Tank: A = 0.50 m², h = 0–2 m, SP = 1.00 m. The actuator is continuously adjustable. Its inlet flow has a 2 s first-order lag: dq/dt = (0.020 × u/100 × supply − q)/2. Level follows dh/dt = (q − qout)/A. Source loss makes the target inlet flow zero. Residual flow decays; a zero command does not instantly stop liquid motion.
    Parallel control: e = SP − PV; Jtrial = J + Ki × Ts × e; raw = 50 + Kp × e + J + D. Applied command is limited to 0–100%. P disables I and D; PI disables D. PID uses a filtered negative PV derivative: d = (Tf × d_previous − (PV − PV_previous))/(Tf + Ts), D = Kd × d. Conditional integration rejects changes that worsen saturation.
    CASCADE: the outer PI output becomes a flow target (0–100% of 0.020 m³/s). Inner PI compares this target with measured flow, with Kp_inner = 1 and Ki_inner = 0.8 s⁻¹ plus a nominal target feedforward. Both loops execute at Ts in this model. Their dynamic responses, not merely task rates, must support the cascade design.
    Units: Kp %/m, Ki %/(m·s), Kd %·s/m, Tf and Ts seconds. CPU STOP forces command zero and IDLE. RUN does not start automatic operation: release Start, then press it again. Active TripCause latches TRIPPED; clearing the cause and Reset returns IDLE. A fresh Start enters AUTO. The running PumpEnable expression owns the final permission and can be programmed incorrectly.
    Single scan executes one controller and plant interval while the clock is paused and CPU is RUN. It is unavailable in STOP. Normal Play/Advance also advances the physical process in STOP with command zero. The CPU RUN selector, operator Start, and process playback are three different controls.
    Initial conditions: h = 0.80 m, inlet flow = 0, integrators = 0. Loading a task resets the virtual plant and CPU to STOP. Download preserves the physical state but clears control memories. Level clipping at 0/2 m is a simulation boundary, not an equipment safety function. No real I/O, network, electrical wiring, or vendor project compatibility is provided.
